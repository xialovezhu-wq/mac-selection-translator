# 本机验收记录

日期：2026-10-03。环境：macOS 27.0、Apple Silicon、Hammerspoon 1.1.1。以下是本机实际结果，不是所有应用或所有机器的性能保证。

## 词形、词性与整句修复后的当前状态

- 已复现并修复 `idealists` 被严格标题比较误判的故障。系统词典原本能返回 `idealist`，问题出在本项目拒绝了该规范词条。
- 安装路径中的程序已验证 `idealists`、`students`、`boxes`、`children` 可以返回中文。`idealists` 返回词性“名词”及“空想家；理想主义者；唯心主义者”。
- 不规则词形引用如 `children → child`、`went → go` 已验证。未知词的 not-found 范围不会传入 Dictionary Services。
- 本机英中离线资源状态为 `installed`，已通过官方准备窗口和安装后的 CLI 分别验证。
- 一句话、无标点短句 `I love you`、连续两句均返回完整中文。连续两句的“早上学英语”和“想成为教师”两部分都已断言验证。
- 当前 22 个 Python 用例和 28 个 Lua 断言通过；划词两侧带逗号、引号或括号也保留词形解析和词性。
- 运行中的浮窗组件使用合成选区适配器、实际安装的程序和当前个人索引验证：`idealists` 的词性和中文、`responses` 还原后个人库的两条语境、完整两句译文。相应两个公开合成截图已视觉检查；没有把该组件测试称为新的物理鼠标拖选测试。
- 浮窗组件耗时为 `idealists` 75.7 ms、个人库词形匹配 45.6 ms、两句翻译 151.0 ms；这三个数字不包含物理 AX 捕获。

以下保留首次版本的验收证据。语言包缺失和“只有精确词形”的旧限制已由本次修复解决。

## 已完成

- Swift 原生程序编译、签名和实际英汉词典查询成功。
- 13 个 Python 测试用例通过，包括中文回退、空文本、无效 JSON、长度限制、选文不能执行 shell、整句不冒充首词、私有索引、源文件只读与安装幂等性。
- 24 个 Lua 断言通过，包括 UTF-8、安全裁剪、空选文、有界缓存和多屏坐标边界。
- 两个全局热键在当前本机成功注册并生效。
- TextEdit 当前选区通过翻译热键查询成功。
- Chrome 合成测试页通过实际鼠标拖选和翻译热键显示中文；显示期间前台应用保持 Chrome。
- Chrome 同一合成选区通过朗读热键收到系统语音首字及正常结束回调。
- 空选区没有重放上次查词；Esc 收起浮窗。
- 上述完整 Chrome 测试前后剪贴板 changeCount 相同。产品取词路径没有 Copy 兜底。
- 中文回退浮窗完成视觉检查，仅有中文释义，英文解释、音标和例句已去除。
- 私有英语索引包含 1233 条正式源记录、1167 个精确查询键；源文件 SHA 与当前正式 CSV 一致。
- 个人库分支使用合成选区适配器、真实正式 CSV 和原生 canvas 做组件集成检查，确认优先显示同词的两条个人语境、库内原句、用法及复习备注，并完成视觉检查。这不是额外的一轮物理鼠标拖选验收。
- 用独立的合成 CSV 验证了运行中的索引刷新；源词义改变后，新查询读到了更新值。
- 稳定安装目录和 `init.lua` 托管块已配置；既有配置有本机备份。

## 实测耗时

| 项目 | 单次实测 | 测量范围 |
|---|---:|---|
| Chrome 鼠标划词首次查询 | 72.9 ms | 热键处理开始到原生 canvas 已 show，包含 AX、子进程与绘制调用 |

此前另外一轮 TextEdit 测试中，词典首查为 82.1 ms，重复查词为 7.1–7.3 ms。更早的语音冷使用首字回调为 967.6 ms。因此冷启动语音可能需要约半秒到一秒，不能把热朗读延迟当作第一次使用的保证。

以上没有测量显示器实际刷新或扬声器声波起点，没有足够样本计算 p95。

## 当前范围与限制

- Chrome、TextEdit 的基础选区路径已实测；Safari、PDF、MarginNote、微信及其他应用没有逐一完成验收。
- 实际三屏坐标已经读取，几何边界由测试覆盖；没有完成三屏逐一人工拖选验收。
- 安全输入和密码字段的拒绝分支已实现，当前没有完成所有应用中的密码输入实机验收。
- 首次版本的英中语言包未下载；当前已安装并验证整句翻译，不使用云端回退。
- 当前个人库支持系统词典确认的规范词形；仍不做模糊匹配或搜索整篇历史材料。
- 中文回退提取依赖当前苹果英汉词典文本格式。最多返回十二个中文释义片段，缺少语境时可能包含多个义项。

个人库截图、正式 CSV、私有索引和 Hammerspoon 原配置备份保留在本机，没有放入项目仓库。
