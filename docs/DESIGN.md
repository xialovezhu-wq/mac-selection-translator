# 实现设计

## 目标

在 macOS 阅读应用中选词后，分别通过两个快捷键查询中文释义、朗读原词。响应优先使用已经运行的工具和本地引擎。后续增加了个人英语库优先匹配，以及未命中时只输出中文的要求。

附件的 Easydict 方案作为参考。实际环境已经运行 Hammerspoon 并授予辅助功能权限，苹果英汉词典也可用，因此本项目复用现有常驻环境，开发独立模块和小型原生词典程序。

## 数据流程

```text
⌃⌥⌘T
  → 安全输入 / 应用检查
  → 有界 AX 当前选区读取
  → 当前个人英语库精确匹配
      → 命中：个人释义、原句、用法、复习备注
      → 未命中：本地英汉词典中文释义
          → 未收录：已安装的苹果离线翻译
          → 无语言包：明确提示
  → 鼠标附近的可滚动浮窗

⌃⌥⌘R
  → 同样的选区安全检查
  → 已安装的系统语音
  → 再按同词朗读键停止
```

## 取词与生命周期

跨进程 AX 查询设置单次超时，整个取词搜索限制在 200 ms。只检查焦点元素、鼠标下元素及有限父节点，不读取 `AXValue` 作为选文，不遍历正文。安全输入、密码字段和明确拒绝的应用返回提示。

每次翻译分配 generation。新请求、Esc、外部点击或应用切换会使旧请求失效；词典任务在失效后终止，异步回调还需检查请求和原前台 PID。窗口在取词后展示，防止浮窗抢走原选区。

显示面板使用 Hammerspoon 的原生 canvas。按当前鼠标所在屏选择可用 frame，处理负坐标、上方副屏和边缘避让。窗口不是 AX 选区矩形锚定。

## 个人库

只读取正式 `bank/master_bank.csv` 的指定字段。来源句是库内既有原句；候选、未入库 Capture、受保护答案原件和完整会话不参与索引。不同记录保留各自语境和 ID。

私有索引由本机 Python 程序从一致的文件快照生成，保存来源 SHA、修改时间和文件大小。先写权限为 `0600` 的临时文件，再原子替换。文件变更观察和热键时的状态检查触发重建。来源缺失或格式无效时停止个人库查询，退回本地词典，避免使用失效索引。

原 CSV、复习日志和学习状态始终只读。GitHub 不携带个人索引。

## 中文回退

Dictionary Services 的公开接口返回词条文本。程序先检查查到的词条和选词一致，避免把短语合并成另一个词或把整句当成首词。然后提取各词义在例句标记之前的中文释义，不展示英文词条解释和系统例句。只输出已有的中文释义，不调用模型改写。

此提取依赖本机已启用的英汉词典格式；其他词典格式不保证可解析。没有可靠中文结果时按未收录处理，避免将英英解释伪装为中文译文。不同义项缺乏原句上下文时不能自动判断应选哪一义项。

## 性能

个人查词直接命中内存中的精确键。词典请求不启动 Swift 编译器，运行已编译的小程序；启动模块时用合成词预热框架页面。缓存仅在内存中存在，不保存个人查词历史。朗读复用两个语音实例。

报告区分进程启动和词典查询、热键到浮窗、语音首字回调以及未经测量的实际声波起点。验收范围不会扩展为所有应用、所有词或所有机器的保证。

## 回滚

安装器修改范围固定在本模块的文件和有标记的 `init.lua` 块，写前备份。卸载器按同一范围删除，不恢复整个旧配置覆盖其他改动。已有 Hammerspoon 启动项和权限保持原设置。
