# 实现设计

## 目标

在 macOS 阅读应用中选词后，通过两个快捷键查询词性和中文释义、翻译完整句子或朗读原文。响应优先使用已经运行的工具和本地引擎。个人英语库优先匹配；未命中时只输出词性和中文释义。

附件的 Easydict 方案作为参考。实际环境已经运行 Hammerspoon 并授予辅助功能权限，苹果英汉词典也可用，因此本项目复用现有常驻环境，开发独立模块和小型原生词典程序。

## 数据流程

```text
⌃⌥⌘T
  → 安全输入 / 应用检查
  → 有界 AX 当前选区读取
  → 识别单词 / 整句输入模式
      → 单词：系统词典解析词性和规范词形
          → 个人库原词或规范词形命中：词性、个人释义、原句、用法、复习备注
          → 未命中：词性、本地词典中文释义
          → 词典无中文：设备端翻译与明确标记的系统词性识别
      → 整句：完整选区交给苹果英中离线翻译
  → 鼠标附近的可滚动浮窗

⌃⌥⌘R
  → 同样的选区安全检查
  → 已安装的系统语音
  → 再按同词朗读键停止
```

## 取词与生命周期

跨进程 AX 查询设置单次超时，整个取词搜索限制在 200 ms。只检查焦点元素、鼠标下元素及有限父节点，不读取 `AXValue` 作为选文，不遍历正文。安全输入、密码字段和明确拒绝的应用返回提示。

每次翻译分配 generation。新请求、Esc、外部点击或应用切换会使旧请求失效；词典任务在失效后终止，异步回调还需检查请求和原前台 PID。窗口在取词后展示，防止浮窗抢走原选区。

显示面板使用 Hammerspoon 的原生 canvas。按当前鼠标所在屏选择可用 frame，处理负坐标、上方副屏和边缘避让。窗口不是 AX 选区矩形锚定。

## 个人库

只读取正式 `bank/master_bank.csv` 的指定字段。来源句是库内既有原句；候选、未入库 Capture、受保护答案原件和完整会话不参与索引。不同记录保留各自语境和 ID。

私有索引由本机 Python 程序从一致的文件快照生成，保存来源 SHA、修改时间和文件大小。先写权限为 `0600` 的临时文件，再原子替换。文件变更观察和热键时的状态检查触发重建。来源缺失或格式无效时停止个人库查询，退回本地词典，避免使用失效索引。

原 CSV、复习日志和学习状态始终只读。GitHub 不携带个人索引。

## 中文回退

Dictionary Services 的公开接口返回词条文本。程序检查词条覆盖完整查询范围，避免把整句当成首词。单词允许系统词典将复数或时态解析为规范词形，词组仍要求标题一致。数字词条标号不参与词形比较。没有中文的 `plural → child`、`past tense → go` 等原生屈折引用最多追踪四次并检查循环。然后提取各词义在例句标记之前的中文释义，不展示英文解释和系统例句。

词性从词典的词类标题提取，保留名词、形容词、及物动词等并列词类。没有可用词典标注时使用设备端 NaturalLanguage 识别，界面标明来源；不能确认时保留未确认状态。

整句模式显式传入 `forceSentence`，跳过词典首词查询并调用 `TranslationSession.translate` 处理全部选区。SwiftUI 准备窗口通过官方 `translationTask` 和 `prepareTranslation()` 安装或确认语言资源。CLI 仅使用已安装资源会话；译文没有中文时不把英文回显伪装成成功翻译。

此提取依赖本机已启用的英汉词典格式；其他词典格式不保证可解析。没有可靠中文结果时按未收录处理，避免将英英解释伪装为中文译文。不同义项缺乏原句上下文时不能自动判断应选哪一义项。

## 性能

个人库在内存中匹配；词性和规范词形由已编译的小程序提供。启动模块时用合成词预热框架页面。内存缓存保存词典 / 翻译结果和词性，原词模式与整句模式使用不同缓存键；命中缓存后仍重查当前个人索引，避免词库变更后显示旧备注。朗读复用两个语音实例。

报告区分进程启动和词典查询、热键到浮窗、语音首字回调以及未经测量的实际声波起点。验收范围不会扩展为所有应用、所有词或所有机器的保证。

## 回滚

安装器修改范围固定在本模块的文件和有标记的 `init.lua` 块，写前备份。卸载器按同一范围删除，不恢复整个旧配置覆盖其他改动。已有 Hammerspoon 启动项和权限保持原设置。
